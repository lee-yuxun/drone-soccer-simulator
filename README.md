# 足球無人機模擬器

[開啟足球無人機模擬器](https://lee-yuxun.github.io/drone-soccer-simulator/)可直接使用自由飛行、30 關訓練、單人練習賽、同機雙人對抗／合作及模型預覽。區網對戰請使用下方的本機啟動方式。

桌機瀏覽器版。使用 Three.js 渲染，飛行與規則採 120 Hz 固定步進。單機在瀏覽器計算，比賽房間由 Node.js 伺服器計算，並以 WebSocket 向同房玩家同步。

## 啟動

環境需有 Node.js 20.11 以上版本、npm 與支援 WebGL 2 的瀏覽器。

```sh
npm ci
npm start
```

開啟 [本機模擬器](http://127.0.0.1:8766)。按 **Space** 解鎖，按住 **W** 升高，鬆開後讓機體穩定。球門中心離地 2 m。過門請從中央朝球門底線前進。

```sh
npm run start -- --lan
```

1. 房主開啟伺服器印出的 `Wi-Fi:` 網址。其他人用同一 Wi‑Fi 開啟相同網址。
2. 房主在「區網房間」選擇 3v3 或 5v5 並建立房間。其他人輸入四碼代碼。
3. 選手選隊及席位並按「準備」，房主按「開始比賽」。空席由 AI 補位，觀戰者可以留在觀戰席。
4. 裝置若找不到房主，確認使用房主的 IP、兩台裝置沒有被訪客網路隔離，且房主防火牆允許 Node.js 接收連線。預設埠為 8766，可透過 `SIM_PORT` 環境變數調整。伺服器須保持運行，單靠靜態頁面能玩單機，區網房間需由此伺服器提供。

短暫中斷連線時，瀏覽器會使用房間憑證重連。座位保留兩分鐘，離線飛手可由 AI 接手。伺服器結束後房間與權威比賽狀態會清除。

## 操作

| 功能 | 預設鍵位 |
| --- | --- |
| 解鎖／鎖定馬達 | Space |
| 油門升／降 | W／S |
| 左／右偏航 | A／D |
| 俯仰與滾轉 | 方向鍵 |
| 翻正、重設、停槳 | T、Z、X |
| 切換視角、暫停 | C、Esc |

操作列的「雙搖桿」可切換觸控控制。手機、平板預設將左搖桿放在左側操作油門與偏航，右搖桿放在右側操作俯仰與滾轉。支援兩指同時控制，也可在球場左右半邊從任意觸點拖曳，放手回中。設定可切換美國手 Mode 2 或日本手 Mode 1；鍵盤按鍵依飛行功能分配。短螢幕橫放時，搖桿移到球場下方兩角。

### 連接 ELRS 遙控器或手把

1. **藍牙**：相容的 ESP32 發射模組可在 ExpressLRS Lua 工具選擇 **BLE Joystick**，再到手機或平板的系統藍牙設定配對。[ExpressLRS 官方說明](https://www.expresslrs.org/quick-start/transmitters/lua-howto/#ble-joystick-esp32-txes-only)
2. **有線**：使用支援資料傳輸的 USB 線，必要時加 OTG 轉接器，在 EdgeTX 遙控器端選擇 **USB Joystick**。[EdgeTX 官方說明](https://manual.edgetx.org/color-radios/model-settings/model-setup/usb-joystick)
3. 用裝置瀏覽器打開上方的 HTTPS 公開版，點「ELRS／手把」，動一下實體搖桿或按鍵。偵測成功後，把兩支搖桿都移到中央，包含不會自動回中的油門，再按目前的 Mode 對應的校正按鈕並依提示操作。
4. 完成後，用即時四軸讀數確認方向。校正依控制器保存於此裝置的瀏覽器，也可手動設定軸向、反轉與死區。

實際相容性取決於控制器、手機或平板的系統及瀏覽器是否將藍牙或 USB 裝置提供為遊戲控制器。若系統能配對但網頁偵測不到，可嘗試另一種連線方式或使用觸控搖桿。

- 初始視角為機尾後方追蹤。可切換 FPV、球門後方、俯視、側邊或自由觀戰；側向視角訓練會從指定視角開始。
- 「對戰」可選單人練習、同機雙人對抗或同機雙人合作，空位由 AI 補上。玩家 1 使用預設鍵盤配置或選定手把。玩家 2 使用 I／K 升降、J／L 偏航、U／O 前後、Y／P 左右、M 解鎖、N 停槳、B 翻正；也可用第二支標準或已校正手把。兩人共用畫面與相機。每局可選 1 分鐘快打或 2 至 5 分鐘。
- 30 個訓練關卡依雛鳥、麻雀、隼鷹排列。全部從地面開始。原本需要空中起點的航線會先顯示起飛提示球，抵達後才開始計時，限時罰球以哨音起算。另有評分、成績 CSV 與路線示範。路線超過標準球場時會使用較大的課程場地。
- 局間有比分與倒數。先贏兩局結束，平局採課程版黃金進球。規則頁列出 FAI 基準與課程差異。
- 在「進球軌跡」選擇個別進球或全場比較，可拖動時間軸、調速、切換視角與色彩、顯示個別選手或匯出 JSON／CSV／PNG。本機保留最近一場含得分的軌跡。比賽進行中每球的精彩片段在得分後兩秒補齊，若恰好完賽則以已採樣區間為止。
- 操作設定與成績存在本機瀏覽器。軌跡使用 IndexedDB；清除網站資料會一併清除紀錄。離開重連可取回運作中的房間，唯比賽中斷時本機只保留接收過的片段。
- 三種進球音效為 Web Audio 合成，按下任一模擬器按鈕後可啟用。瀏覽器需要 WebGL 2。低畫質可隱藏網面以降低負載，碰撞邊界仍存在。

## 專案結構與驗證

| 位置 | 功能 |
| --- | --- |
| `src/sim/config.js`、`flight.js` | 規則設定、固定步進四軸動力學、護籠碰撞、雙向球門判定 |
| `src/sim/game.js`、`training.js` | 比賽狀態機、判分、AI、30 個關卡與評分 |
| `src/sim/trace.js`、`replay.js` | 10 Hz 一般軌跡、30 Hz 得分手精彩片段、分析與回放 |
| `src/sim/app.js`、`view.js`、`browser.js` | 頁面、3D 渲染、鍵盤與 Gamepad API、合成音效 |
| `scripts/server.mjs`、`src/sim/lan.js` | HTTP 與 WebSocket、房間與權威模擬 |
| `assets/`、`src/models.js` | 可另外匯入的原創 GLB 與程序化幾何 |
| `test/simulator.test.js` | 核心單元與流程測試 |

```sh
npm test
npm run build
```

`build` 重新匯出 GLB，模擬器的 HTML／JavaScript 原始檔可直接由伺服器提供。Chrome 已驗證 WebGL、起飛、鍵盤重設、Turtle 關卡、成績、進球回放、房間建立和窄螢幕。以 6 及 10 個 WebSocket 飛手客戶端加一個觀戰者，分別驗證 3v3、5v5 選位鎖定、Ready、權威座標同步與重連。另驗證 5v5 以操控訊息完整穿門後，觀戰者收到比分，並可取得對應進球軌跡。尚未用兩台實體裝置或實體 USB 手把驗收，也沒有逐一人工飛完 30 關。規則引擎實作教學用簡化處置，正式賽事仍以公告及現場裁判為準。

驗收腳本可在伺服器運行時重跑。區網測試預設使用本機，也可傳入 `ws://房主IP:8766/room`。瀏覽器測試請先以獨立的 Chrome 使用者資料目錄啟動遠端偵錯埠 9225。

```sh
npm run test:lan
npm run test:browser
```

## 建模參考

在 [3D 模型預覽](http://127.0.0.1:8766/models.html) 可單獨檢視球場、無人機和遙控器，也可下載三個 GLB。

- 球場參考 OURSTEAM TDA193，場地內徑 6 × 3 × 3 m，氣柱直徑 25 cm。雙側懸門位於 X = ±2 m、高 2 m，開口直徑 40 cm、外徑 70 cm、厚度 10 cm。[OURSTEAM 產品頁](https://www.oursteam.com.tw/view-product.php?id=1258)
- 無人機與遙控器依 IMG_1367–1371 建模，幾何尺寸部分依照片估算。單位為公尺，Y 軸向上，球場長邊沿 X。
- 正式規則參考 FAI Sporting Code Volume F9 Drone Sports 2026 第 2 版，2026 年 6 月 1 日生效。[FAI 規則來源](https://www.fai.org/page/sporting-rules-0)
